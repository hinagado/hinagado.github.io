第1条 この規約について

  1. この規約は、ひなが堂 制作室（以下「当店」）が行うホームページ・チラシの制作（以下「制作」）と、月額の保守（以下「保守」）に共通するお約束です。
  2. ココナラなどの仲介サイトからお申し込みいただいた場合は、そのサイトの規約が優先します。この規約は、そのサイトの規約と食い違わない範囲でだけ使います。
  3. 見積書に、この規約と違う取り決めを書いた場合は、見積書が優先します。

第2条 当店のやり方

  1. 当店は、文章・プログラム・画像づくりに AI を使って制作時間を短くし、人が確かめてから納品します。確かめるのは当店の点検表の項目（誤字・脱字、リンク切れ、スマホの幅で横にはみ出さないか、文字と背景の色の差、表示の速さ、AI 画像が既存の作品に似ていないか、景品・値引きの見せ方・言い過ぎの表現・医療や化粧品などの広告の決まりに触れそうな所）で、点検の結果は納品の時にお知らせします。広告の決まりについては気づいた所をお知らせするところまでで、最終の判断はお客様または専門家にお願いします。
  2. やりとりは文字が基本です（申し込みフォーム・メール・共有のフォルダ。仲介サイトではそのサイトのメッセージ）。ご希望があれば、どの業種でもオンライン（ビデオ通話）での打ち合わせをお受けします（無料）。電話でのご相談はお受けしていません。第11条の2の確認が要る業種のご依頼では、オンラインでの打ち合わせを必ず1回行います。
  3. 当店がやりとりに対応するのは、土曜・日曜・祝日・年末年始を除く日の10時〜17時です。当店の返信は、原則として2営業日以内です。保守のお客様への返信の目安は、プラン表のプランごとの目安のとおりです（ライト 3営業日以内・スタンダード 2営業日以内・しっかり 1営業日以内）。ホームページが表示されないなどの障害のご連絡は、受け取った後、できる限り速やかに対応します。
  4. お預かりした文章・写真は、制作のために AI のサービスに入力することがあります。当店は、入力した内容を AI の学習に使わない設定・契約のサービスを選びます（使うサービスはプライバシーポリシーに書いています）。お客様の顧客・利用者・従業員の個人情報は、文章の素材に含めないでください（人が写っている写真の扱いは第12条6項のとおりです）。

第3条 契約の成り立ち

  1. 申し込みフォームの送信は見積もりのご依頼で、まだ契約ではありません。
  2. 当店が見積書（作る物・値段・お支払いの時期・納期の目安・直しの回数・キャンセルの扱い）をお送りし、お客様が承諾のご連絡をして、1回目のお支払いが済んだ時に契約が成り立ちます。確認が要る業種（第11条の2）のご依頼は、同意書をいただいていることも条件です。
    当店は、お支払いを確認したら、承諾したことと、受け取った額・提供の時期・当店の事業者情報をメールでお知らせします。ホームページの残金と、保守の毎月のお支払いを受け取ったときも、同じようにお知らせします。
  3. 当店は、お引き受けできない内容（第11条）や、空きがない場合は、理由を添えてお断りすることがあります。
  4. 当店は小さな個人の店で、引き受けるのは週1件まで、同時に進めるのは2件までです。

第4条 お支払い

  1. お支払いは銀行振込です。振込手数料はお客様のご負担です。
    当店は消費税のインボイス（適格請求書）の登録をしていません。表示の金額がお支払いの総額です。お支払いは銀行振込だけで、振込手数料はお客様のご負担です。
  2. お支払いの時期は次のとおりです。
    • チラシ：全額前払い
    • ホームページ（チラシと一緒のご依頼を含む）：着手時に50％、公開の前に残り50％
    • 保守：公開した月の翌月から数えます。はじめの月の分は、公開の時にホームページの残りの料金と一緒に。2か月目からは毎月、その月の分を前月末までに
  3. お支払いが遅れた場合、当店は、お支払いがあるまで作業（ホームページの公開・更新、投稿づくりを含みます）を止めることがあります。止めた間は、納期の目安もその日数だけ延びます。遅延の損害金は請求しません。

第5条 お客様にご用意いただく物

  1. 文章の原稿・写真・ロゴなどの素材は、見積書に書いた期限までにお送りください。
  2. ドメインと公開先のアカウントは、お客様の名義で作っていただきます（作り方は文字で1画面ずつご案内します）。当店は、作業に必要な権限だけをお借りします。パスワードそのものではなく、共同作業の招待などの方法を使います。招待の仕組みがない公開先は、おすすめしません。
  3. 公開先のアカウントづくりは、ご契約の前（見積もりの段階）にお願いします。うまくいかないときは、ご契約に進まずにやめられます（費用はかかりません）。ドメインの取得は、公開の前までで大丈夫です。
  4. 素材が届かないために作業が止まった場合、納期はその分遅れます。

第6条 納期

  1. 納期は「素材がそろい、構成案が確定してから」の目安です。お約束の日ではありません。
  2. 当店の都合で目安より大きく遅れる見込みのときは、すぐにお知らせし、新しい目安をお伝えします。お客様は、それに納得できないときは第10条の扱いで契約をやめられます（その場合、当店の都合なので作業の割合による費用はいただかず、受け取った額をお返しします）。「大きく遅れる」とは、お伝えした目安の日数の2倍を超えるときをいいます。

第7条 直し（修正）の数え方

  1. 直しは次の3種類に分けます。
    • 軽い直し：お客様の原稿の言い回し・電話番号・営業時間などの差し替え（お客様の原稿に元からあった誤字の直しを含む）、写真1〜2枚の入れ替え
    • デザインの直し：色合い・文字の大きさ・並び順・写真の配置の変更
    • 構成の変更：ページの追加・削除、全体の雰囲気の作り直し、確定した内容の大幅な入れ替え
  2. 軽い直しとデザインの直しは、料金表に書いた回数（デザインの作り方とページ数で決まります）まで料金に含みます。直したい所は、当店がお送りする「直しの依頼表」に書いてご返信いただいた1枚を1回と数えます。送った後に思い出した所は、依頼表を受け取ってから24時間以内なら同じ1回に足せます（当店は、それまで作業を始めません）。
  3. 次のものは当店の誤りとして、回数に入れず無料で直します。
    • 当店が入れた誤字・脱字、リンク切れ、スマホでの表示の崩れ
    • 見積書、ご確認いただいた構成案、申し込みのお答えに書かれた内容と明らかに違う所
    • 「雰囲気が思っていたのと違う」など、書かれた内容と違うとは言えないものは「デザインの直し」です。迷うときは、当店から先に「どちらに当たるか」をお知らせしてから作業します。
  4. 回数を超える直しと構成の変更は、追加料金表または見積もりでお受けします。作業の前に料金をお知らせし、ご了承をいただいてから進めます。

第8条 確認と納品

  1. 当店は、公開の準備ができたら、確認用のアドレスと点検の結果をお送りします。
  2. お客様は、確認用のアドレスを見て、14日以内に「公開してよい」か直したい所をお知らせください。
  3. 14日たってもご連絡がないときは、当店からもう一度ご連絡し、作業をいったん止めてお待ちします。ご連絡がないことを「承認した」とはみなしません。
  4. 最初のお知らせから60日たってもご連絡がつかないときは、第10条6項のとおり扱います。
  5. チラシは、印刷用のデータ（PDF）と画像のお渡しで納品です。印刷の色は機械や紙で変わるため、画面と完全に同じにはなりません。

第9条 公開後の不具合

  1. 公開（チラシは納品）から6か月以内に、当店の作業が原因で、見積書の内容と違う所や正しく動かない所が見つかったときは、無料で直します。
  2. 6か月を過ぎた後も、当店の作業が原因の不具合が見つかった場合は、民法など法令の定めに従って対応します。
  3. 次のものは当店の作業が原因の不具合には当たりません：お客様や第三者が後から加えた変更、公開先・ドメインの会社の障害や仕様の変更、インターネットを見るアプリ（Safari・Chrome など）の大きな仕様の変更、お客様がお送りくださった素材の誤り。

第10条 キャンセル（お客様からの中止）

  1. お客様は、納品の前ならいつでも契約をやめられます。
  2. その場合、当店は、それまでの作業の割合に応じた額だけをいただき、残りはお返しします。目安は次のとおりです（制作費に対する割合）。
    やめた時点いただく額の目安
    着手の連絡の前0％（全額お返し）
    構成案をお送りした後20％
    デザイン案（初稿）をお送りした後50％
    公開の準備ができた後80％
  1. この割合は、その時点までに通常かかる作業時間の割合から決めています。ご希望があれば、根拠をご説明します。
  2. 当店の誤り（第7条3項）を直すようお求めいただき、当店が直せなかったためにやめる場合は、第2項によらず、受け取った額を全額お返しします。
  3. お返しするときの振込手数料は当店が負担します。
  4. 当店からお客様に、60日以上ご連絡がつかないときは、ご連絡のうえで契約を終え、第2項の目安で精算することがあります。

第11条 お引き受けしない内容

次の内容は、お引き受けしないか、途中でもお断りすることがあります（途中の場合は第10条の目安で精算します。当店の判断が誤っていたときは全額お返しします）。

  3. 医療・健康・お金などについて、効果や結果を言い切る内容（医療広告ガイドライン・医薬品医療機器等法・景品表示法などの決まりに触れるおそれのあるもの）

第11条の2 確認が要る業種のご依頼

第12条 素材と権利

  1. お客様がお送りくださった素材（文章・写真・ロゴ・図など）は、お客様が使ってよい権利をお持ちのものに限ります。その素材が原因で第三者と問題になったときは、お客様の責任で解決していただきます。ただし、当店が素材を勝手に作り変えたことが原因のときは除きます。
  2. 当店が AI で作った画像は、公開の前に、よく知られた作品やロゴに似ていないかを当店が確かめます。ただし、世の中のすべての作品と比べることはできないため、似ていないことを完全には保証できません。似ているとご指摘を受けたときは、すぐに差し替えます（無料）。
    当店が作った画像について、第三者から権利の侵害を言われたときは、当店がお客様と一緒に対応します（事情の説明・差し替え・資料の提出）。お客様に損害が出たときの当店の責任は、第17条のとおりです（お客様に押しつけることはしません）。
  3. AI で作った画像や文章には、法律上の著作権が生まれない場合があります。そのため、他の人が似た物を使うのを止められないことがあります。
  4. 納品物のうち、当店に著作権などの権利が生まれる部分は、代金のお支払いが全部済んだ時にお客様へ移ります（著作権法の27条・28条の権利を含みます）。AI で作った部分には、第3項のとおり権利が生まれない場合があります。
    当店は、お客様とお客様から使うことを認められた方に対して、著作者人格権を使いません（お客様が納品物を自由に直して使うことに異議を言いません）。
  5. ただし、当店が他のお客様にも使う型（テンプレート）や部品の権利は当店に残ります。お客様は、納品されたサイト・チラシの中でそれらをずっと無料で使えます。
  6. 写真に人（従業員・お客様のお客さんなど）が写っている場合は、写っている方から載せることの同意を得たうえでお送りください。同意があるか分からない人が写っていることに当店が気づいたときは、お知らせし、その写真を載せないことがあります。
  7. 当店は、お客様の許可がある場合だけ、完成品を当店の実績として載せます。許可は任意のお願いで、許可するかどうかで値段は変わりません。お客様の顧客の情報は載せず、載せた後でもご連絡から14日以内に外します。

第13条 保証しないこと

当店は、検索での順位、問い合わせの数、売上、集客の効果を保証しません。ページの検索対策は、基本の設定（ページ名・説明文など）を行うところまでです。

第14条 フォームで集める個人情報

  1. お客様のホームページに置くお問い合わせフォームを作るとき（当店への見積もりのご依頼のフォームのことではありません）、フォームで集めた情報（お客様の顧客の名前・連絡先など）は、お客様に直接届く作りにします。当店のサーバーやメールには残しません。フォームを作るたびに、試しに送って確かめます。
  2. フォームで集めた情報をだれが見るか・どのくらいの期間とっておくかは、お客様が決め、お客様のサイトのプライバシーポリシーに書いてください。当店は、ひな形の文をお作りします（内容の最終確認はお客様）。
  3. 保守の作業中に、やむを得ず届いた情報を見ることがあっても、作業以外に使わず、外に漏らしません。
  4. 当店が申し込みでお預かりしたお客様の情報は、制作・保守・ご連絡・会計の記録のためだけに使い、法令で保存が求められる期間（帳簿はおおむね7年、そのほかの書類はおおむね5年）が過ぎたら消します。

第15条 保守（月額）

  1. 保守の内容は、プラン表のとおりです。使わなかった回数は翌月へ繰り越しません。
  2. 最低契約期間はありません。やめたい月の前の月の末日までにご連絡いただければ、やめたい月の末日で終わります（例：11月30日でやめたいときは、10月31日までにご連絡ください）。
  3. 当店から保守をやめるときは、2か月前までにお知らせします（第11条に当たるとき、お支払いが2か月以上ないときを除く）。
  4. 公開先・ドメインの利用料は保守に含みません。お客様の名義で直接お支払いください。期限が近づいたら当店からお知らせします（お知らせが漏れても、更新の手続きはお客様の名義の契約です）。
  5. 値段を変えるときは、2か月前までにお知らせします。お客様は、新しい値段になる前に、追加の費用なくやめられます。
  6. ホームページや地図アプリ（Google マップなど）に載せる営業時間・店の情報は、お客様からいただいた内容をそのまま載せます。内容を変えるときは、変える日の3営業日前までにお知らせください。期限を過ぎたご連絡も、できる限り早く直しますが、直る日はお約束できません。

第15条の2 集客の立ち上げと SNS 運用

  1. Instagram・Facebook・Google マップなどのアカウントは、お客様の名義のままにします。今あるアカウントは、そのまま使います。当店は、お客様に管理画面で「担当者」や「管理者」として招いていただいた権限で作業し、パスワードはお預かりしません。
  2. 当店が作った投稿は、お客様の承認をいただいてから出します。承認は、共有のフォルダかメールの返信でいただきます。承認のない投稿は出しません。
  3. 投稿を出した後のコメント・DM（メッセージ）への返事と、そこから来たお問い合わせへの対応は、お客様が行います。当店は返事をしません。
  4. Instagram・Google など外部のサービスの仕様の変更・障害、アカウントの停止や制限によって、作業の一部ができなくなったときは、代わりの方法をお客様と相談し、できなくなった作業の分の料金は、その月から減らします。
  5. 集客の立ち上げと SNS 運用は、来店・問い合わせ・フォロワーの数を約束するものではありません（第13条の「集客の効果」に当たります）。

第16条 解約したときの引き渡し

保守が終わったとき、当店は次のことをします。

  1. サイトのデータ一式（ページ・画像・文章）を圧縮ファイルでもお渡しします。
  2. 使っている画像の一覧と、出どころ（お客様の素材／AI画像）をお渡しします。
  3. 当店が借りていた公開先・ドメインの権限を外し、外したことをご報告します。
  4. 当店の作業用の下書き・AI への指示文・型（テンプレート）の元データはお渡ししません（サイトに入っている分はそのまま使えます）。

第17条 損害の賠償

  1. 当店の作業に故意または重大な過失があってお客様に損害が出たときは、法令に従って賠償します（次の上限はありません）。
  2. 当店の作業に、故意・重大な過失でない過失（軽い過失）があってお客様に損害が出たときに当店が賠償する額は、次を上限とします。
    • 制作：その制作で当店が受け取った制作費
    • 保守：損害が出た月から数えて直近6か月に受け取った管理料
  3. 第2項の上限は、軽い過失の場合だけに使います。

第18条 仲介サイトから来たお客様

仲介サイト（ココナラなど）からお申し込みいただいたお客様とは、そのサイトの外でやりとり・お支払いをしません（そのサイトの決まりのため）。公開先への招待など、作業にどうしても必要なことは、そのサイトの決まりの範囲で行います。

第19条 規約の変更

この規約を変えるときは、当店の HP で変更の内容と始まる日を、始まる日の1か月前までにお知らせします。すでに結んだ制作の契約には、結んだ時の規約を使います（お客様が新しい規約を選んだ場合を除く）。

第20条 法律と裁判所

この規約は日本の法律に従います。もし裁判になったときは、法令に従って決まる裁判所で行います。
