中身の見本

画面のデータは架空の例です。画像を押すと大きく開きます。

こんな人に

  • 毎年お正月に、おい・めい・孫など何人にもお年玉を渡している
  • 「あの子、今年は何年生？」「去年はいくら入れた？」と毎年考えこむ
  • 新札を何枚用意すればいいか、前もって数えておきたい
  • 管理表を買う前に、自分に使えるかどうか試してみたい

できること

  • 学年の目安が自動で出る：生年月日を書くと、お正月のころの学年（年長・小2・中1 など）が出ます。4月1日生まれ（早生まれ）の数え方もそのとおりに計算。生年月日がわからず生まれ年だけのときは「小1（早生まれなら小2）※目安」のように出ます
  • 相手ごとに、今年と去年の金額が並ぶ：「年ごとの記録」シートで、2年分を1行で見られます
  • 今年の準備がすぐわかる：予定の合計・渡した分・まだの分、ポチ袋の数、一万円札・五千円札・千円札と硬貨の数（できるだけ少ない枚数で数えます）
  • 「渡した」を選ぶと、まだの分だけの枚数も出る
  • 書き間違いにも気づける：金額がマイナス・小数・文字のとき、年が4けたの数字でないとき、リストにない名前のときは「〇〇を確認」「リストにない相手」と出ます。「〇〇を確認」「〇〇を入れて」の行は合計に入りません。「リストにない相手」は、警告を出したうえで合計に入ります。
  • 相手の名前はリストから選ぶだけ
  • お年玉の金額の相場は書いていません。ご家庭で決めた金額をそのまま書けます

中身

Excel ファイル（.xlsx）1つ。シートは5枚です。

  1. 使い方 … 3ステップの説明。やさしい言葉で書いています。いちばん下に全部入り版のご案内があります
  2. 相手リスト … お年玉をあげる相手（10人まで）。学年の目安が自動で出ます
  3. あげた … 年ごとに、だれに・いくら（40行まで）
  4. 今年の準備 … 予定の合計・新札と硬貨の枚数・ポチ袋の数（自動）
  5. 年ごとの記録 … 相手ごとに今年と去年の金額（自動）
  • 例の行（架空の名前）入り。消してからお使いください
  • 計算式のマスは、誤って消さないようにロックしています（パスワードなし。外すこともできます）
  • A4で印刷できる設定にしています。印刷の前にプレビューで確認してください
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。

ご注意

  • 無料でお配りしているお試し版です。ファイルが壊れていて開けない等の不具合は、BOOTH のメッセージからご連絡ください
  • お試し版で書いた内容は、全部入り版にそのまま移す仕組みはありません。必要なときは書き写してください
  • 学年は、学校教育法などの決まり（4月2日生まれから次の年の4月1日生まれまでが同じ学年）にそって数えた目安です。入学を1年おくらせた、海外の学校に通っている、などのときは実際の学年と違います。高校の学年は年齢から数えた目安です。
  • お札・硬貨の枚数は「大きいお札から順に使う」数え方の目安です。二千円札は数に入れていません。新札の用意のしかたは、お使いの金融機関でお確かめください。
  • 入力した内容は、お客様が保存したファイルの中だけに残ります。ひなが堂に送られることはありません。
  • 実在の人物とは関係ありません。例の名前はすべて架空です
  • ファイルの再配布・転売はご遠慮ください
