できること

入っているもの（6点）

ひなが堂で1点ずつ売っている商品を、そのままの中身で6点まとめたセットです。1点ずつお求めいただくより、お安くしています。

  1. 家族の もしもの時の 連絡・情報メモ：家族の連絡先を1つに。カードと冷蔵庫の紙に
  2. 家族の 書類・資格・契約の 更新期限 まとめ表：免許も保険も資格も、更新の日を家族ぶん1枚に
  3. 家族の保険 まとめ表：家族の保険を1つの表に。もしものときは家族が見られる
  4. 家電・保証書 管理表（Excel）：保証の切れる日と、保証書のありかが1枚で分かる
  5. 防災備蓄 チェック表（家族の人数で必要な量・賞味期限の切れ目が分かる）：人数を入れるだけ。足りない量と期限切れが分かる
  6. エンディングノート：もしものとき、家族が困らないように

それぞれの商品の くわしい説明は、1点ずつの商品ページをご覧ください。

使う順番のめやす

どれから使ってもかまいません。迷ったら、この順番がおすすめです。

  1. 家族のもしもの時の連絡・情報メモ：まず、家族の連絡先を1つにまとめます。
  2. 家族の書類・資格・契約の更新期限まとめ表：免許・保険・資格などの更新の日を、家族ぶん書いておきます。
  3. 家族の保険まとめ表：家族の保険を1つの表にまとめます。
  4. 家電・保証書管理表：家電の保証の切れる日と、保証書のありかを書いておきます。
  5. 防災備蓄チェック表：家族の人数を入れて、備蓄の足りない量と期限切れをたしかめます。
  6. エンディングノート：最後に、自分のこと・家族へのことば・大切な物のありかをまとめます。

中身

  • zip ファイル 1つ。中に、商品ごとのフォルダが6つと、セットのご案内（PDF）が入っています
  • フォルダの中身は、1点ずつ売っている商品と同じファイルです（Excel のファイルと、その商品の「はじめにお読みください」PDF）
  • セットのご案内（PDF）に、入っているものの一覧と、使う順番のめやすを書いています
  • マクロ（VBA）は使っていません。計算式だけで作っています。
  • Excel のファイルには、はじめての方にも分かる やさしい言葉の「使い方」シートがあります
  • 例の行（架空）が入っている商品は、消してからお使いください

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
