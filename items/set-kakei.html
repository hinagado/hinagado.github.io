こんな人に

  • 家計簿をつけたいけれど、それだけでは「年に1回の出費」や「毎月の引き落とし」まで目が届かない
  • サブスクや光熱費など、毎月出ていくお金を一度まとめて見直したい
  • 旅行・車・税金など、先の出費に向けて毎月いくら取り分ければいいか知りたい
  • ポイントやギフト券を、期限切れで失いたくない

できること

入っているもの（6点）

ひなが堂で1点ずつ売っている商品を、そのままの中身で6点まとめたセットです。1点ずつお求めいただくより、お安くしています。

  1. サブスク・定期払い 整理表（Excel）：毎月いくら？が1枚で分かる、やさしい整理表
  2. 2027年 日付入り家計簿：日付はもう入っています。その日の行に書くだけ
  3. 光熱費・水道代 記録表（Excel）：電気・ガス・水道を、月にならして前の年とくらべる
  4. 1年の 特別費 予算表：税金も行事も旅行も。毎月の取り分け額がすぐ出る
  5. 目標貯金 進み具合表：旅行も車も。毎月いくら貯めればいいかすぐわかる
  6. ポイント・ギフト券・クーポン 期限まとめ表（Excel）：期限が近い順に並ぶ、ポイントのまとめ表

それぞれの商品の くわしい説明は、1点ずつの商品ページをご覧ください。

使う順番のめやす

どれから使ってもかまいません。迷ったら、この順番がおすすめです。

  1. サブスク・定期払い整理表：はじめに、毎月・毎年決まって出ていく支払いを書き出して、合計を知ります。
  2. 2027年日付入り家計簿：毎日の出費は、日付の入った家計簿へ。その日の行に書くだけです。
  3. 光熱費・水道代記録表：検針票や明細が届いたら、電気・ガス・水道の金額を書きます。月にならして前の年とくらべられます。
  4. 特別費予算表：税金・行事・旅行など、毎月ではない出費を1年分書き出して、毎月の取り分け額を出します。
  5. 目標貯金進み具合表：旅行や車など目標のある貯金は、こちらで進み具合を見ます。
  6. ポイント・ギフト券期限まとめ表：ポイント・ギフト券・クーポンは、期限が近い順に並べて、使い忘れを防ぎます。

中身

  • zip ファイル 1つ。中に、商品ごとのフォルダが6つと、セットのご案内（PDF）が入っています
  • フォルダの中身は、1点ずつ売っている商品と同じファイルです（Excel のファイルと、その商品の「はじめにお読みください」PDF）
  • セットのご案内（PDF）に、入っているものの一覧と、使う順番のめやすを書いています
  • マクロ（VBA）は使っていません。計算式だけで作っています。
  • Excel のファイルには、はじめての方にも分かる やさしい言葉の「使い方」シートがあります
  • 例の行（架空）が入っている商品は、消してからお使いください

動く環境
