できること

どちらを選ぶ？

  • 頒布物が4個までで、X むけの横長だけでよい → このお試し版で足ります
  • 頒布物が5個以上ある → このお試し版で、全部ならべた形を「見るだけ」で確かめてから、全部入り版へ
  • 5個以上ある／正方形・縦長・A4 の印刷用もほしい／色やデザインをえらびたい／値札も作りたい → 全部入り版
  • サークル名・スペース番号・イベント名・日付・ひとこと・連絡先を書けます
  • 保存できるのは「頒布物4個まで・横長 1920×1080・デザイン シンプル・色3つ（さくら・そら・モノクロ）」のお品書きです
  • 頒布物は、1つずつ「札・題名・値段・サイズやページ数・ひとこと（あらすじ）・書影や写真」を書けます
  • ほかの大きさ（正方形・縦長・A4）・デザイン（ポップ・ダーク・和風・クラフト紙）・色・5〜12個の並びは「見るだけ」です。画像に「お試し版の見本・保存は全部入り版で」の字が入り、保存のボタンは押せなくなります。「保存できる見た目にもどす」で、もとにもどせます
  • 並べ方は自動です。「大きく見せる」に印をつけた物（新刊など）は、ほかより大きい枠になります
  • 札は「新刊・既刊・グッズ・無配・委託・自由に書く（6字まで）・札なし」。「完売」「残りわずか」、年齢の表示（全年齢・R18）の札もつけられます
  • サークルのマークと、背景の画像を重ねられます
  • 長い文字は、枠に入るように自動で小さくなります（入りきらない分は「…」）
  • 「背景を透明にして保存」「枠だけを透明で保存」も使えます
  • 「当日の更新」を開くと、題名と状態だけの一覧で「完売」「残りわずか」をまとめて変えられます。サークル名・スペース番号・題名・値段が空のときは、画面で知らせます
  • 書いた内容と画像は同じブラウザにおぼえます。入力と画像を1つのファイルに保存して、あとで読みこめます（全部入り版でも読みこめます）

動く環境

確かめたこと・確かめていないこと

  • 全部入り版と合わせて 679,453 件の自動チェックを流し、合わない所は 0 件でした（Windows 11 の Google Chrome で、実際に HTML を開いて流しています）。このうちお試し版だけの確かめは 8,753 件で、頒布物の並べ方、字が枠に入ること、保存した PNG の大きさ、保存した画像に見本の字が入らないこと、見るだけの形では保存されないこと などです
  • 確かめていないこと: スマホ・タブレットの実機、Mac、Safari・Firefox・Edge での保存。実際のサークルさんに使ってもらう試しは、まだしていません
  • Windows 11 のパソコンの Google Chrome で、動作を確かめています
  • スマホの幅でも画面が横にはみ出さないことは確かめていますが、スマホ・タブレットの実機、Mac、Safari・Firefox・Edge での保存は確かめていません

ご購入前のご注意

利用のきまり

  • お使いいただけるのは、ダウンロードした方おひとりです。ご自身のサークルのお品書きにも、頼まれて代わりに作るお品書きにも、いくつでも使えます
  • 作った画像（PNG）は、SNS での告知・印刷して机に置く・通販ページの画像・チラシなどに使えます（使ってよい場面の説明です。お試し版で保存できるのは、横長 1920×1080 の画像です。A4 の大きさはありません。紙に印刷することは確かめていません）。個人でも法人でも、有料で頒布・販売するイベントでも使えます。クレジットの表示や報告はいりません
  • 作った画像は、サークルの主さんや、ご依頼くださった方に渡せます。作った画像の加工もできます
  • メーカー（HTML）のファイルそのものは、ほかの人に渡したり、配ったり、売ったりできません。使いたい方には、このページをお知らせください

ご注意

  • デザインは図形と色だけです。手描きの飾りのような装飾はありません
  • 枠の位置や大きさを、手で動かすことはできません（自動の並べ方だけです。順番は入れかえられます）
  • 年齢の表示（全年齢・R18）の札は、字を入れるだけの物です。イベントや通販サイトの決まりに合った表示かどうかは、ご自身でお確かめください
  • 見本の画像に写っているキャラクター（おもち と仲間）と、見本の本やグッズの絵は付きません。見本のサークル名・イベント名・題名は架空のものです
  • 入力した文字や画像を外へ送るしくみは入れていません。すべてお使いのパソコンの中で動きます
  • ファイルが開けない等の不具合は BOOTH のメッセージからご連絡ください
