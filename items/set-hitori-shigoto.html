できること

入っているもの（7点）

ひなが堂で1点ずつ売っている商品を、そのままの中身で7点まとめたセットです。1点ずつお求めいただくより、お安くしています。

  1. 開業準備チェック表：開業日を入れるだけ。届けの期限と準備が一目で
  2. 届出と税金の年間カレンダー：年を入れるだけ。届出と税金の時期が1年で見える
  3. 見積書・納品書・請求書メーカー（インボイス対応）：明細を1回入れれば、見積書・納品書・請求書に
  4. フリーランス 売上・入金管理表（Excel）：入金もれ・振込額のちがいに、すぐ気づける表
  5. 交通費・経費の精算表：往復は自動で2倍。まだ精算していない分がひと目で
  6. 副業の収支 記録表（Excel）：会社員の副業の「収入−経費」と20万円の目安が分かる
  7. 締切から逆算する 段取り表：締切を入れるだけ。「いつ始めればいい？」が分かる

それぞれの商品の くわしい説明は、1点ずつの商品ページをご覧ください。

使う順番のめやす

どれから使ってもかまいません。迷ったら、この順番がおすすめです。

  1. 開業準備チェック表：開業日を入れて、届けの期限と準備をたしかめます。
  2. 届出と税金の年間カレンダー：年を入れて、1年の届出と税金の時期を見ておきます。
  3. 見積書・納品書・請求書メーカー：仕事を受けたら、明細を1回入れて、見積書・納品書・請求書を作ります。
  4. フリーランス売上・入金管理表：請求したら売上を書き、入金を確かめます。入金もれ・振込額のちがいに気づけます。
  5. 交通費・経費の精算表：交通費や立て替えた経費を書いておきます。まだ精算していない分がひと目で分かります。
  6. 副業の収支記録表：会社員の副業なら、こちらで「収入−経費」を記録します（フリーランスが本業の方は、売上・入金管理表を中心にどうぞ）。
  7. 締切から逆算する段取り表：締切のある仕事は、締切を入れて「いつ始めればいいか」を出します。

中身

  • zip ファイル 1つ。中に、商品ごとのフォルダが7つと、セットのご案内（PDF）が入っています
  • フォルダの中身は、1点ずつ売っている商品と同じファイルです（Excel のファイルと、その商品の「はじめにお読みください」PDF）
  • セットのご案内（PDF）に、入っているものの一覧と、使う順番のめやすを書いています
  • マクロ（VBA）は使っていません。計算式だけで作っています。
  • Excel のファイルには、はじめての方にも分かる やさしい言葉の「使い方」シートがあります
  • 例の行（架空）が入っている商品は、消してからお使いください

動く環境
