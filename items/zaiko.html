使っているところ

音は出ません。画面のデータは架空の例です。

こんな人に

  • ハンドメイド作家さん・小さなお店で、材料や商品の数をノートや頭の中で数えている
  • 「あの材料、まだあったっけ？」と、作りはじめてから気づくことがある
  • どの仕入れ先に、何を、いくつ注文すればいいか、まとめて知りたい
  • 棚のすみで、ずっと動いていない在庫が気になっている
  • 表計算は苦手。でも、日付と数を書くだけなら使えそう

できること

  • 商品・材料を 200品目まで 登録できます。同じコードは2回登録できません（書くときに止まり、計算でも2つ目は数えません。前後の空白や英字の大文字・小文字だけがちがうコードも同じとみなします）
  • 入庫（仕入れた・作った）と出庫（売れた・使った）を 2000行まで 書くと、品目ごとの 今の在庫 が出ます
  • 発注点（ここまで減ったら注文する数）と 発注する数 を書くと、「注文が必要な物」の一覧が 仕入れ先ごと に並んで出ます。注文の金額の目安も出ます
  • 「まとめ」シートで、仕入れ先ごと の品目の数・注文が必要な数・在庫の金額が分かります
  • 最後に動いた日からの日数 が出ます。しばらく動いていない在庫（はじめは90日。日数は変えられます）は、古い順に一覧になります
  • 在庫の金額 が出ます。単価は「総平均」（はじめの在庫と、記録を始めた日から基準日までに仕入れた分をならした単価）で出します。いちばん最後の仕入れ単価ではありません。在庫のようすを見るための、おおよその目安です。会計・税務申告の帳簿としてはお使いいただけません
  • 棚卸し で数えた数を書くと、表の数との 差 と、その金額が出ます
  • 日付に文字が入った・数がマイナス・表にないコード・登録の行に書きまちがいがある品目・先の日付などは「〜を確認」とお知らせし、その行は数に入れません。コードを書きかえて古い行が数えられなくなったときは、何行あるかを朱色で知らせます

中身

Excel ファイル（.xlsx）1つ。シートは7枚です。

  1. 使い方 … 3ステップの説明。はじめての方にも分かる、やさしい言葉で書いています
  2. 商品・材料 … 品目を登録するところ（コード・名前・仕入れ先・発注点・はじめの在庫数など）
  3. 入出庫の記録 … 書きこむところ。黄色いマスに、日付・コード・入庫か出庫か・数を書くだけ
  4. まとめ … 品目の数・在庫の金額・注文が必要な数・お知らせ、区分ごと・仕入れ先ごとのまとめ
  5. 注文が必要な物 … 発注点まで減った品目の一覧（仕入れ先ごと）
  6. 動いていない在庫 … しばらく動いていない在庫の一覧（古い順）
  7. 設定 … 基準日・記録を始めた日・動いていないとする日数・仕入れ先の名前
  • 例の行（名前に「（例）」とある架空の品目）が入っています。消してからお使いください
  • 計算式が入ったところは、誤って消さないためのロックをかけてあります（パスワードなし。外すこともできます）
  • A4 で印刷できる設定です。印刷の前にプレビューで確認をお願いします
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
  • 計算式は、昔からある基本的なものだけを使っています（XLOOKUP など新しい関数は使っていません）。
  • 行や人数が足りなくなったら、ファイルをコピーして2冊目としてお使いください。

  • 在庫の金額・注文の金額は目安です。実際の値段は、仕入れ先でお確かめください
  • バーコードの読み取り・ネットショップとの自動の連携はありません。数は手で書きこみます
  • 入力した内容は、お客様が保存したファイルの中だけに残ります。ひなが堂に送られることはありません
  • デジタル商品のため、お客様都合の返品・返金はお受けできません。ただし、ファイルが壊れていて開けない等の不具合は BOOTH のメッセージからご連絡ください
