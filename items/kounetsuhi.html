こんな人に

  • 電気代やガス代が「去年より高い気がする」けれど、去年の請求書が見つからない
  • 水道代は2か月に1回の請求なので、ほかとならべて比べにくい
  • 請求の期間が「9月10日〜10月9日」のように月をまたいでいて、何月の分なのか分かりにくい
  • 1年でいくら払ったか、ざっくり知りたい
  • 表計算は苦手。でも、請求書の数字を書き写すだけなら使えそう

はじめての方にも分かる、やさしい言葉で書いています。

できること

  • 請求書（検針票）1枚につき1行で、種類・請求の期間（開始日と終了日）・請求額・使用量（kWh・㎥・L）を書きとめられます（300行まで。4種類を毎月書いても6年分ほど）
  • 種類は 電気・ガス・水道 と、もう1つ（はじめは「灯油」。名前は変えられます）
  • 1行ごとに 1日あたりの金額 と 単位あたりの金額（1kWh あたり など）が出ます
  • 月にならして比べられます: 請求額を期間の日数で割って、それぞれの月に日割りで分けます。2か月ごとの水道代も、月をまたぐ期間も、うるう年の2月29日も、同じ決まりで分けます
  • 「月ごと」のシートで、前の年の同じ月との比べが「＋1,234円 増えた」「－567円 減った」「同じ」「前年の記録なし」のように出ます（その月の全部の日に記録があるときだけ比べます）
  • 「年のまとめ」のシートで、年の合計（金額・使用量）、1日あたりの平均、記録のそろい方 が5年分ならびます
  • グラフ（月別の金額） が2つ: 種類ごとの積み上げと、合計を前の年とくらべるグラフ。グラフにする年は数字を書きかえるだけで変わります
  • 期間の重なり（同じ請求を2回書いた など）は「上の行と期間が重なっています」と知らせて、合計に入れません。期間の抜けは「前の記録との間が○日あいています」と知らせます
  • 灯油のように 買った日だけのもの は「買った日」の書き方にでき、その日の月に全額が入ります
  • 日付や金額に文字が入ったとき、期間が長すぎるときなどは「〇〇を確認（合計に入っていません）」とお知らせします
  • 表に出る5年は「最初の年」を書きかえるだけで進められます（記録は消えません）

中身

Excel ファイル（.xlsx）1つ。シートは5枚です。

  1. 使い方 … 3ステップの説明と、月にならす しくみ
  2. 設定 … 表の最初の年・4つ目の種類の名前・単位・書き方（期間／買った日）
  3. 記録 … 書きこむところ。黄色いマスに、請求書の数字を書くだけ
  4. 月ごと … 5年分の月ごとの金額と、前の年の同じ月との比べ
  5. 年のまとめ … 年の合計・1日あたりの平均・使用量・記録のそろい方・グラフ
  • 例の行（架空の金額）が61行入っています。消してからお使いください
  • お客様番号・住所・契約の名前などを書く欄はありません
  • 計算式が入ったところは、誤って消さないためのロックをかけてあります（パスワードなし）
  • A4 で印刷できる設定です。印刷の前にプレビューで確認をお願いします
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
  • 計算式は、昔からある基本的なものだけを使っています（XLOOKUP など新しい関数は使っていません）。
  • 行や人数が足りなくなったら、ファイルをコピーして2冊目としてお使いください。

  • 月の金額は、請求額を日数で割って分けた「めやす」です。実際の請求の月とは合わないことがあります（円の位で四捨五入するので、1円ほどの差が出ることがあります）
