使っているところ

音は出ません。画面のデータは架空の例です。

こんな人に

  • 体重を測っても、メモがばらばらで、増えたか減ったか分からなくなる
  • 「次のトリミング、いつだっけ？」「予防薬、今月あげたかな？」が、ときどきある
  • 通院やワクチンの日を、カレンダーとメモ帳と頭の中に分けて覚えている
  • フードや病院代など、1年でいくらかかっているか知りたい
  • 2匹・3匹いて、だれの分か分からなくなる
  • 表計算は苦手。でも、日付と数字を書くだけなら使えそう

できること

  • ペット3匹まで（犬・猫・その他）。名前と誕生日を書くと、年齢（○歳○か月）と、次の誕生日まであと何日かが出ます（2月29日生まれにも対応。うるう年でない年は2月28日に1つ年をとる数え方です）
  • 体重の記録（300回まで）。前の回との差が自動で出て、ペットごとの体重の推移のグラフができます
  • 通院・ワクチン・予防薬・トリミングなどのお世話の記録（300回まで）。「次の予定日」を書くか、間隔（○か月・○週・○日）を書くと、次の予定日が出ます。間隔は、ご自身で決めて書きます
  • 「予定」シートに、予定日が近いもの・過ぎたものが、日の早い順に一覧で出ます。過ぎたものは朱色、近いもの（はじめは14日以内。日数は変えられます）は黄色です
  • お世話をしたら新しい行に書くだけ。前の予定は自動で「済み」になります
  • 費用の記録（500回まで）。「費用のまとめ」シートに、月別・種類別の合計と、ペットごとの1年の合計が出ます。みんなで使うフードなどは「共通（みんなの分）」で分けられます
  • 費用の種類（フード・医療・用品・トリミング・保険など）と、お世話の種類は、名前を変えたり足したりできます
  • 日付に文字が入ったとき、金額に「円」が入ったときなどは「〜を確認」とお知らせし、合計やグラフには入れません

中身

Excel ファイル（.xlsx）1つ。シートは9枚です。

  1. 使い方 … 3ステップの説明。はじめての方にも分かる、やさしい言葉で書いています
  2. ペット … 名前・種類・誕生日を書くところ。年齢・最新の体重・予定の数が出ます
  3. 体重 … 日付・ペット・体重（kg）を書くところ
  4. 体重のグラフ … ペットごとの体重のグラフ（自動）
  5. お世話の記録 … 通院・ワクチン・予防薬・トリミングなどを書くところ
  6. 予定 … 次の予定日の一覧（自動）
  7. 費用 … 日付・ペット・種類・金額を書くところ
  8. 費用のまとめ … 月別・種類別・ペット別の合計（自動）
  9. 設定 … 基準日・まとめる年・お知らせする日数・種類の名前
  • 例の行（名前に「（例）」とある行）が入っています。消してからお使いください
  • 計算式が入ったところは、誤って消さないためのロックをかけてあります（パスワードなし。外すこともできます）
  • A4 で印刷できる設定です。印刷の前にプレビューで確認をお願いします
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
  • 計算式は、昔からある基本的なものだけを使っています（XLOOKUP など新しい関数は使っていません）。
  • 行や人数が足りなくなったら、ファイルをコピーして2冊目としてお使いください。

  • 健康のことは、かかりつけの獣医師に相談してください。 次の予定の間隔も、獣医師と相談して決めた間隔などを、ご自身で書いてください
