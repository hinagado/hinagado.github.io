できること

入っているもの（6点）

ひなが堂で1点ずつ売っている商品を、そのままの中身で6点まとめたセットです。1点ずつお求めいただくより、お安くしています。

  1. 1年の目標と 月のふりかえり シート：今年の目標、いまどのくらい？が毎月わかる
  2. 習慣トラッカー（1年分）：できた日に ○ を入れるだけ。続いた日数が見える
  3. 体重と目標の記録表（1年分）：入れるだけで、7日の平均とグラフが出る
  4. 読書記録ノート：1冊ずつ書くだけ。今年の読書が数字で見える
  5. 映画・ドラマ・アニメ 視聴記録ノート：見た作品を1行ずつ。今年の本数と好きな傾向が見える
  6. 誕生日・記念日とプレゼント 記録帳：大切な日まで「あと何日」と、あげた物が1冊に

それぞれの商品の くわしい説明は、1点ずつの商品ページをご覧ください。

使う順番のめやす

どれから使ってもかまいません。迷ったら、この順番がおすすめです。

  1. 1年の目標と月のふりかえりシート：年のはじめに目標を書き、毎月ふりかえります。
  2. 習慣トラッカー：続けたいことを決めて、できた日に○を入れます。
  3. 体重と目標の記録表：体重をはかったら入れます。7日の平均とグラフが出ます。
  4. 読書記録ノート：本を読み終えたら1冊ずつ書きます。
  5. 映画・ドラマ・アニメ視聴記録ノート：見た作品を1行ずつ書きます。
  6. 誕生日・記念日とプレゼント記録帳：家族や友だちの大切な日を書いておくと、「あと何日」が分かります。

中身

  • zip ファイル 1つ。中に、商品ごとのフォルダが6つと、セットのご案内（PDF）が入っています
  • フォルダの中身は、1点ずつ売っている商品と同じファイルです（Excel のファイルと、その商品の「はじめにお読みください」PDF）
  • セットのご案内（PDF）に、入っているものの一覧と、使う順番のめやすを書いています
  • マクロ（VBA）は使っていません。計算式だけで作っています。
  • Excel のファイルには、はじめての方にも分かる やさしい言葉の「使い方」シートがあります
  • 例の行（架空）が入っている商品は、消してからお使いください
