中身の見本

画面のデータは架空の例です。画像を押すと大きく開きます。

できること

  • A6（文庫）105×148mm の表紙を作れます。背幅（0〜50mm・0.1mm きざみ）と塗り足し（3mm・5mm）を入れると、画像の大きさを自動で出します
  • 右とじ（縦書きの本）・左とじ（横書きの本）を切りかえられます。「表4＋背＋表1」と「表1だけ」をえらべます
  • 題名・副題・著者名・上の小さな字・裏表紙のサークル名とひとこと を書けます。題名は たて書き・よこ書き をえらべます
  • 背には題名と著者名が入ります（背幅が 3.5mm より細いときは入れません）
  • デザインは「二重罫」、インクは3色（墨・紺・えんじ）、地紋は七宝、紙の色は白・生成り
  • 字と飾り枠は、仕上がりの線から 5mm より内側に置きます。長い字は自動で小さくなります（入りきらない分は「…」）
  • 見本に確認用の線（仕上がり・塗り足し・背の折り目）を出せます。印刷用の画像には入りません
  • 印刷所のテンプレートを PNG か JPEG にした画像（トンボや余白をふくまない物）を、見本にうすく重ねて見くらべられます
  • 表1 に、お手持ちの絵・ロゴを重ねられます（大きさと位置を動かせます）。題名は、大きさと位置を変えられます
  • 背幅の調べ方の案内と、入稿の前に確かめることのチェック欄が画面にあります
  • 印刷用の PNG（350dpi カラー・RGB。解像度を画像に記録）、確認用の PNG（線つき）、地を透明にした PNG を保存できます
  • 保存した画像に、お店の名前やロゴは入りません

全部入り版とのちがい

  • 判型: お試し版は A6（文庫）だけ／全部入り版は A6・新書・B6・A5＋自由に入れる
  • デザイン: お試し版は二重罫だけ／全部入り版は 二重罫・題箋・上下の帯・丸紋・角かざり・細罫
  • 地紋: お試し版は七宝だけ／全部入り版は 七宝・市松・青海波・たてじま・うろこ・水玉
  • インク: お試し版は3色／全部入り版は 10色＋好きな色
  • 紙の色: お試し版は白・生成り／全部入り版は 白・生成り・うすい色・色ベタ（白ぬき字）
  • 保存: お試し版は 350dpi の PNG／全部入り版は 350dpi・600dpi の PNG、600dpi グレースケール、600dpi モノクロ2階調、PDF
  • 透明の素材: お試し版はなし／全部入り版は 12柄・全480枚（飾り枠 240・地紋 240）

動く環境

  • 実際に印刷所へ入稿して刷る試しは、まだしていません。
  • Windows 11 のパソコンの Google Chrome で、動作を確かめています（機械での計算と保存の試験 151,639 件・合わない所 0 件。全部入り版とお試し版を合わせた数です。印刷所で受け付けられることを確かめた数字ではありません）
  • 字の形は、お使いのパソコンに入っている明朝・ゴシックを使います（Windows は游明朝・游ゴシックで確かめています。字は同梱していません）
  • ほかに確かめていないこと: スマホ・タブレットの実機、Mac、Safari・Firefox・Edge での保存も確かめていません

ご購入前のご注意

利用のきまり

  • お使いいただけるのは、ダウンロードした方おひとりです。ご自身の本にも、表紙づくりを頼まれた方の本にも、何冊分でも使えます
  • 作った表紙は、同人誌・個人出版の本・電子書籍の表紙・お品書きや通販ページの見本画像などに使えます。有料で頒布する本でも使えます。クレジットの表示や報告はいりません
  • 作った表紙の画像は、ご依頼くださった方に渡せます（代わりに作って納品することができます）
  • 作った画像の、加工・色の変更・絵や写真との重ね合わせができます
  • メーカー（HTML）のファイルそのものは、ほかの人に渡したり、配ったり、売ったりできません。ほかの方もメーカーを使うときは、その方がこのページからダウンロードしてください
  • くわしくは、同梱の「使い方と利用のきまり」（PDF）をご覧ください

ご注意

  • 背幅の自動計算はしません。お使いの印刷所の計算表・計算ページで出た数字を入れてください
  • 色は RGB です（CMYK ではありません）。入稿できるファイルの形・解像度・塗り足しの幅は、印刷所によってちがいます。入稿の前に、印刷所の手引きとテンプレートで、大きさと左右（表1・表4）をお確かめください
  • 重ねられる絵は表1 に1枚です。絵はブラウザにはおぼえません。PNG で入稿できるかは印刷所によってちがいます（PSD だけの印刷所もあります）
  • カバー（そで付き）・帯の大きさには対応していません
  • 入力した文字を外へ送るしくみは入れていません。すべてお使いのパソコンの中で動きます
  • ファイルが開けない等の不具合は BOOTH のメッセージからご連絡ください
