できること

入っているもの（6点）

ひなが堂で1点ずつ売っている商品を、そのままの中身で6点まとめたセットです。1点ずつお求めいただくより、お安くしています。

  1. 大掃除 チェック表：日にちと時間を入れるだけ。今日やることがすぐわかる
  2. 年賀状・喪中 やりとり管理表（Excel）：今年だれに出すか、枚数まで自動で分かる
  3. 2027年 ひつじ年の年賀状ひな形 10種（はがきサイズ PNG・PDF）：ひつじのおもちが届ける、やさしい年賀状
  4. 年末年始の段取り表：年末年始の用事を日ごとに。済んだら残りが減る
  5. お年玉 管理表（あげた・もらった）：「去年いくらだっけ？」をもう迷わない。
  6. 2027年 書きこみカレンダー：印刷しても、Excelでも。2027年の予定を1冊に

それぞれの商品の くわしい説明は、1点ずつの商品ページをご覧ください。

使う順番のめやす

どれから使ってもかまいません。迷ったら、この順番がおすすめです。

  1. 大掃除チェック表：12月に入ったら、大掃除の場所と日にちを決めます。今日やることがすぐ分かります。
  2. 年賀状・喪中やりとり管理表：年賀状を出す相手と枚数を決めます。喪中はがきが届いたことも、ここに書いておきます。
  3. 2027年ひつじ年の年賀状ひな形：出す枚数が決まったら、ひな形（10種）から選んで印刷します。
  4. 年末年始の段取り表：年末年始の用事を日ごとに並べます。済んだら残りが減っていきます。
  5. お年玉管理表：お正月に、あげた・もらったお年玉を書いておきます。次の年に「去年いくら」が分かります。
  6. 2027年書きこみカレンダー：新しい年の予定は、このカレンダーへ。印刷しても、Excel のままでも使えます。

中身

  • zip ファイル 1つ。中に、商品ごとのフォルダが6つと、セットのご案内（PDF）が入っています
  • フォルダの中身は、1点ずつ売っている商品と同じファイルです（Excel のファイルと、その商品の「はじめにお読みください」PDF。年賀状のひな形は PNG と PDF）
