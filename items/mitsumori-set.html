こんな人に

  • 小さなお店や個人の仕事で、見積書・納品書・領収書を毎回 Word や手書きで作っている
  • 3つの書類に、同じ品名や金額を何度も書き写している
  • 領収書もきちんとした形で出したい。但し書きや支払い方法も書きたい
  • 10% と 8%（軽減税率）の品が混ざると、消費税の計算に自信がない
  • 登録番号（インボイス）を持っている人も、持っていない人も使える物がほしい
  • パソコンは苦手。むずかしい設定なしで使いたい

できること

  • 「書類の入力」のシートに品目（品名・数量・単価・税率）を1回入れると、「見積書」「納品書」「領収書」の3つのシートに同じ品目が写ります。どれも A4 縦1枚で印刷できます（明細は20行まで）
  • 自分の情報（屋号・住所など）と取引先（50件まで）を一度入れておけば、あとはリストから選ぶだけ
  • 見積書・納品書・領収書それぞれに、番号と日付を入れられます。見積書には有効期限、領収書には「但し書き」と「お支払いの方法」も出ます
  • 消費税は、国税庁の案内にそって、1枚の書類ごとに 10%・8% それぞれ1回だけ端数を処理して出します（明細の1行ずつには計算しません）。端数は「切り捨て・四捨五入・切り上げ」から選べます。単価は税抜き・税込みのどちらでも入れられます
  • 8% の品には自動で「※」の印がつき、「※は軽減税率（8%）の対象です」と出ます
  • 登録番号の欄は任意です。入れたときは「T＋13桁」の形をチェックし、納品書・領収書にインボイスの記載事項（6つ）が入力されているかを自動で確かめます（中身が正しいかまでは判断しません）。空のときは登録番号なしの書き方（消費税は「消費税相当額」）になり、インボイスにはなりません（名前・取引の日などの基本のチェックはします）
  • 合計が5万円以上になると、「領収書は収入印紙が要る場合があります（国税庁で確認）」とお知らせし、領収書に印紙をはる所の枠が出ます（要るかどうかの判定はしません）
  • 入れまちがい（数量に文字・税率の選びわすれ・日付の書きまちがいなど）は「確認」の欄でお知らせし、合計には入れません。書類ごとに「OK」か「確認」が分かります

中身

  • Excel ファイル 1つ（.xlsx）
  • シートは7つ: 「使い方」／「自分の情報」／「取引先」（50件）／「書類の入力」（明細20行）／「見積書」／「納品書」／「領収書」（どれも A4 縦1枚）
  • 「使い方」のシートは、はじめての方にも分かる、やさしい言葉で書いています（3ステップ）
  • 計算式のマスにはロック（誤って消さないためのもの）がかかっているので、うっかり消してしまうのを防げます（パスワードはかけていません）
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
  • 計算式は、昔からある基本的なものだけを使っています（XLOOKUP など新しい関数は使っていません）。
  • 取引先や行が足りなくなったら、ファイルをコピーして2冊目としてお使いください。

ご購入前のご注意

  • この表で作った書類が、すべての場合にインボイスの要件を満たすことを保証するものではありません。くわしくは国税庁の案内・税務署へ
  • 収入印紙が要るかどうか・いくらかは判定しません。国税庁の案内でお確かめください
  • この表は書類を作るための道具です。税金・印紙税の計算や申告、登録をするかどうかなどのご相談にはお答えできません
  • 3つの書類は同じ品目になります（書類ごとに品目を変えることはできません）。番号は手で入れ、自動では増えません。請求書・振込先の欄はありません（請求書は別の商品「見積書・納品書・請求書メーカー」で作れます）
  • 返品・値引きのあとに出す書類（適格返還請求書）、レシート形式の書類（適格簡易請求書）には対応していません
  • 印刷の前に、印刷プレビューで見え方を確かめてください
  • 例として入っている名前（「ひな形工房（例）」「株式会社〇〇（例）」など）は架空のものです。消すか書きかえてお使いください
  • デジタル商品のため、お客様のご都合による返品・返金はお受けできません。ただし、ファイルが壊れていて開けないなどの不具合は、BOOTH のメッセージからご連絡ください
  • 再配布・転売はご遠慮ください
