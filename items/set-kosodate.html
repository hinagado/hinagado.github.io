できること

入っているもの（7点）

ひなが堂で1点ずつ売っている商品を、そのままの中身で7点まとめたセットです。1点ずつお求めいただくより、お安くしています。

  1. 入園・入学・進級 準備リスト：持ち物を書くだけ。残りと金額がひと目で分かる
  2. 学校のプリント・提出物・行事 管理表：プリントを書くだけ。締切の近い順がひと目で分かる
  3. 子どもの習い事 月謝・送迎 管理表（Excel）：月謝も送り迎えも、1冊でまるっと整理
  4. 子どもの予防接種・健診 記録と予定：予定日を書くだけ。近い予定・すぎた予定が色で分かる
  5. 子どもの成長記録（身長・体重・できたこと）：はかった日を入れるだけで、年齢と変化が分かる
  6. 子どもの おこづかい帳（3人まで）：書くだけで、おさいふとちょきんが自動でわかる
  7. おてつだい ポイント表（ごほうびと交換）：おてつだいに○。ためたポイントでごほうび

それぞれの商品の くわしい説明は、1点ずつの商品ページをご覧ください。

使う順番のめやす

どれから使ってもかまいません。迷ったら、この順番がおすすめです。

  1. 入園・入学・進級準備リスト：新しい年度の前に、持ち物と金額をリストにして、そろえ残しを防ぎます。
  2. 学校のプリント・提出物・行事管理表：学校が始まったら、もらったプリントを書いていきます。締切の近い順がひと目で分かります。
  3. 習い事の月謝・送迎管理表：習い事を始めたら、月謝と送り迎えをこちらでまとめます。
  4. 予防接種・健診の記録と予定：予防接種や健診の予定日を書いておくと、近い予定・すぎた予定が色で分かります。
  5. 子どもの成長記録：身長・体重をはかった日に書きます。年齢と変化が分かります。
  6. 子どものおこづかい帳：おこづかいを始めたら、子どもと一緒に書きます（3人まで）。
  7. おてつだいポイント表：おてつだいに○をつけて、ためたポイントをごほうびと交換します。

中身

  • zip ファイル 1つ。中に、商品ごとのフォルダが7つと、セットのご案内（PDF）が入っています
  • フォルダの中身は、1点ずつ売っている商品と同じファイルです（Excel のファイルと、その商品の「はじめにお読みください」PDF）
  • セットのご案内（PDF）に、入っているものの一覧と、使う順番のめやすを書いています
  • マクロ（VBA）は使っていません。計算式だけで作っています。
  • Excel のファイルには、はじめての方にも分かる やさしい言葉の「使い方」シートがあります
  • 例の行（架空）が入っている商品は、消してからお使いください

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
