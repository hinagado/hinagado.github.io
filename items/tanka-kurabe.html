使っているところ

音は出ません。画面のデータは架空の例です。

こんな人に

  • 5kg と 2kg、12ロールと6ロール。どっちが得なのか、売り場で迷う
  • 同じ品物が、どの店でいちばん安かったか覚えていられない
  • 「最近値上がりしたかも」を、記録で確かめたい
  • g と kg、ml と L がまざっていて、計算がめんどう
  • 家の買い物をまとめて担当している
  • パソコンは苦手。むずかしい設定なしで使いたい

できること

  • 見かけた値段を 300行まで 書けます。日付・品目・店・商品の名前やメモ・値段・内容量・単位・入り数（まとめ売りの数）
  • 書くと 単価が自動で 出ます。品目ごとに「1kgあたり」「100gあたり」「1個あたり」など、くらべ方を自分で決められます
  • g と kg、ml と L は自動でそろえて くらべます（2000g と 5kg も、そのままくらべられます）
  • トイレットペーパーは「1ロールの長さ × ロールの数」で書くと、長さあたり でくらべられます
  • その品目で いちばん安い記録に★ がつきます
  • 同じ店（店のリストにある店）の前の記録とくらべて、何％上がった・下がった が出ます
  • 「くらべた結果」のシートで、品目ごとに いちばん安い単価と店・いちばん新しい値段・店ごとの単価 が1枚で見られます（いちばん安い店に色がつきます）
  • 「最近90日」のように、くらべる期間 を日数でしぼれます
  • 店は10こ、品目は30こまで、自分に合わせて書きかえられます
  • 数字でない・単位が合わない・先の日付などの書きまちがいは、色と「注意」の列で知らせます
  • A4で印刷できます（印刷する前に、印刷プレビューで見え方を確かめてください）

中身

  • Excel ファイル 1つ（.xlsx）
  • シートは4つ: 「使い方」／「設定」（店・品目・くらべる期間）／「値段メモ」（300行）／「くらべた結果」
  • 「使い方」のシートは、はじめての方にも分かる、やさしい言葉で書いています
  • 例として、架空の店（「スーパーA（例）」など）と値段が入っています。消してからお使いください
  • 計算式のマスにはロック（誤って消さないためのもの）がかかっているので、うっかり消してしまうのを防げます（パスワードはかけていません）
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
  • 計算式は、昔からある基本的なものだけを使っています（XLOOKUP など新しい関数は使っていません）。
  • 行や人数が足りなくなったら、ファイルをコピーして2冊目としてお使いください。
