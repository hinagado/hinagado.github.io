使っているところ

音は出ません。画面のデータは架空の例です。

こんな人に

  • 家族や友だちの誕生日を、気づいたら過ぎていたことがある
  • 「今年で何歳だっけ？」「結婚して何年目？」と、毎回数えている
  • 去年なにをあげたか忘れて、同じ物をまたあげてしまいそうで心配
  • いただいたプレゼントも、だれから何をもらったか残しておきたい
  • 表計算は苦手。でも黄色いマスに書くだけなら使えそう

できること

  • 誕生日・記念日を 200件まで 書きとめられます（名前・間柄・誕生日か記念日か・月・日・年・メモ）
  • 次に来る日と「あと何日」 が自動で出ます。今日がその日なら「今日」と出て色が変わります
  • 生まれた年（記念日なら始まりの年）を入れると、次の日に何歳になるか・何周年か が出ます。年が分からない人は空のままでOK
  • 2月29日生まれの人は、うるう年でない年は 2月28日 に出します（この表のきまりです。うるう年は 2月29日）
  • 「もうすぐ順」シート：次に来る日の近い順に、全員が並びます。近い日（はじめは30日以内）は色でお知らせ
  • プレゼント記録（300行）：あげた物・もらった物を、日付・相手・品物・金額（空でもOK）で残せます
  • 同じ物を2回あげると「前にもあげた（2回目）」 と出ます。「もうすぐ順」には、その人に前にあげた物と日付も出ます
  • 「人ごと」シート：名前を選ぶと、その人の誕生日・記念日と、やりとりの記録が新しい順に出ます。あげようと思う物を書くと「前にもあげています（最後は 2026/4/12）」のように分かります
  • 「年ごと」シート：10年分と、1年の月ごとに、あげた・もらった件数と金額が出ます
  • 「月の一覧」シート：年と月を入れると、その月の誕生日・記念日が日の順に並びます。A4 で印刷して、冷蔵庫や手帳に
  • 月が 13 になっている、4月31日になっている、金額がマイナス、といった書きまちがいは「〇〇を確認」とお知らせします

中身

Excel ファイル（.xlsx）1つ。シートは8枚です。

  1. 使い方 … 3ステップの説明。はじめての方にも分かる、やさしい言葉で書いています
  2. 設定 … 「もうすぐ」とみなす日数（はじめは30日）、間柄の名前
  3. 誕生日・記念日 … 書きこむところ（200行）
  4. もうすぐ順 … 近い順の一覧（自動）
  5. プレゼント記録 … あげた・もらったを書くところ（300行）
  6. 人ごと … 1人ずつのやりとり（自動）
  7. 年ごと … 年・月ごとの件数と金額（自動）
  8. 月の一覧 … 印刷用の月ごとの一覧（自動）
  • 例の行（架空の名前）が入っています。消してからお使いください
  • 計算式が入ったところは、誤って消さないためのロックをかけてあります（パスワードなし。外すこともできます）
  • A4 で印刷できる設定です。印刷の前にプレビューで確認をお願いします
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
  • 計算式は、昔からある基本的なものだけを使っています（XLOOKUP など新しい関数は使っていません）。
  • 行や人数が足りなくなったら、ファイルをコピーして2冊目としてお使いください。
