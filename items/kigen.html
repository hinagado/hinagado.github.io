使っているところ

音は出ません。画面のデータは架空の例です。

こんな人に

  • お店のポイント・商品券・クーポンが、気づいたら期限切れになっていた
  • お財布やスマホのあちこちに、ポイントやギフトカードが散らばっている
  • 「今月中に使わないといけない分は、いくら分あるの？」をすぐ知りたい
  • 回数券やマイルも、まとめて1か所で見たい
  • 表計算は苦手。でも書くだけで並べ替えてくれる表がほしい

できること

  • ポイント・商品券・ギフトカード・クーポン・回数券・マイルなどを、1行に1つずつ書くだけで記録できます（100件まで）
  • 種類・お店（名前は自分で書きます）・残り・単位（ポイント／円／枚／回／マイル）・期限・使える場所のメモを書けます
  • 「1あたり何円」を自分で入れると、円にするといくらか を自動で出します（単位が「円」なら空けたままで大丈夫です）
  • 「期限順」シートに、期限が近いものから自動で並びます。期限なしのものはその下、期限が切れたものはいちばん下にまとまります
  • 期限まで 30日以内は朱色、7日以内は濃い朱色、切れたものは灰色 で目立たせます
  • 「まとめ」シートで、今月中に切れる分の合計額 と まだ使えるもの全部の合計額 が分かります
  • 7日以内・30日以内の件数と金額、種類ごとの合計も自動で出ます
  • 種類と単位は、リストから選ぶだけ（名前は自分で変えられます）

中身

Excel ファイル（.xlsx）1つ。シートは4枚です。

  1. 使い方 … 3ステップの説明。はじめての方にも分かる、やさしい言葉で書いています
  2. 記録 … 書きこむところ。黄色に書くだけで、うすい青のところは自動で計算されます
  3. 期限順 … 期限が近い順に自動で並ぶ一覧
  4. まとめ … 今月中に切れる分・全部の合計・期限が近いもの・種類ごと
  • 例の行（架空のお店の名前）が7行入っています。消してからお使いください
  • 計算式が入ったところは、誤って消さないためのロックをかけてあります（パスワードなし。外すこともできます）
  • A4で印刷できる設定です。印刷の前にプレビューで確認してください
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
