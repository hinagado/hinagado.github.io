中身の見本

画面のデータは架空の例です。画像を押すと大きく開きます。

こんな人に

  • 大掃除を毎年ぎりぎりまで先のばしにしてしまう
  • 「どこから手をつけるか」「1日にどれだけやればいいか」で迷う
  • チェック表を買う前に、自分に使えるかどうか試してみたい
  • パソコンは苦手。むずかしい設定なしで使いたい

できること

  • 「はじめる日」「終わらせたい日」「1日に使える時間（分）」を入れるだけで、やることを毎日に割り当てます（1日の時間をこえないように、上の行から順に詰めていく、シンプルな仕組みです）
  • やることは 15行まで 書けます。キッチン・浴室・トイレ・リビング・窓・玄関などの 代表的なやること10項目 と かかる時間のめやす が最初から入っていて、空き行5行に自分のやることを足せます
  • 使わない項目は「×」を選ぶだけ。かかる時間は自分の家に合わせて直せます
  • 「先に」「あとで」を選ぶと、割り当ての順番が変わります
  • 1日の時間をこえる大きなやることは、自動で何日かに分けます。終わらせたい日までに入りきらないときは「入りきらない」と知らせます
  • 「今日」のシートに、今日やること と 遅れている物 が出ます（それぞれ10件まで）
  • 家族の担当をリストから選べます。「進み具合」のシートで、家じゅうの進み具合 が棒で見えます
  • 洗剤の「まぜるな危険」など、安全の注意 を公的機関の案内をもとに短くまとめています（全部入り版と同じ）

中身

Excel ファイル（.xlsx）1つ。シートは6枚です。

  1. 使い方 … 3ステップの説明と安全の注意。いちばん下に全部入り版のご案内があります
  2. 設定 … 日にち・1日の時間・家族の名前・場所の名前
  3. やること … 書きこむところ（15行）。黄色に書くだけで、予定日と状態は自動で出ます
  4. 今日 … 今日やること・遅れている物
  5. 毎日の予定 … 1日ごとの割り当て（60日まで）
  6. 進み具合 … 家じゅうの進み具合
  • 例として入っている名前（「Aさん（例）」など）は架空のものです。消すか書きかえてお使いください
  • 計算式が入ったところは、誤って消さないためのロックをかけてあります（パスワードなし。外すこともできます）
  • A4で印刷できる設定です。印刷の前にプレビューで確認してください
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
