早見

  • 値段: 無料
  • 使い方: ①「要素」（人物・伏線・設定など）と「場面」を書き、どの要素がどの場面に出るかを「つながり」に1行ずつ書く → ②「変える」で要素を選ぶ → ③「直す場所」に、結んでおいた場面が章の順で並ぶ
  • 中身: Excel のファイル2つ（記入例・白紙）＋使い方の PDF
  • 動作を確かめた環境: Windows 11 のパソコンの Excel
  • 記入例: 短編ミステリー『閉店後の古書店と、消えた初版本』（架空・全4章12場面）。犯人を別の人に変えると、直す場所は16か所（うち「必ず直す」11か所）と出ます

こんな人に

  • 書いている途中で設定を変えて、どこを直せばいいのか分からなくなった
  • 推敲のたびに、伏線の回収や、時刻・アリバイの食い違いを見落とす
  • ミステリーで、犯人・アリバイ・証言のつじつまを、書き直したあとも合わせておきたい
  • プロットを組み直す前に、どこまで直しが広がるかを見積もりたい

できること

はじめ方（小さく始めて大丈夫です）

  • まず記入例を開き、「変える」の黄色のセルを E02・E05 などに変えて、「直す場所」が入れかわるのを見てください
  • ご自分の話は、変えそうな物（犯人・時刻・伏線など）を3〜5個と、それが出てくる場面だけ書けば動きます。全部の場面を書く必要はありません（書かなかった場面は「直す場所」に出ないので、確かめたい範囲は書いてください）
  • 強さの目安: 変えると話が通らなくなる所＝必ず直す／読み直して合っているか見る所＝見直す／名前や数字がちらっと出るだけの所＝念のため
  • 最初の10分の例: 要素を3個（例: 犯人／犯人のアリバイ／閉店の時刻）、場面を5個、つながりを5行。人物と、その人の言い分（アリバイ・証言）は、別々に変わることがあるので別の要素に分けます
  • プロットをこれから組む方は、記入例の「要素」「場面」の書き方をまねると、かんたんな一覧としても使えます（プロットの組み立て方を教える物ではありません）
  • 文章の言い回しを添削する表ではありません。話のつじつまを直すための表です
  • 長編で場面が 120 を超えるときは、部や巻ごとにファイルを分けてお使いください（分けたファイルどうしのつながりは出ません）
  • 「要素」: 人物・真相・動機・証言・伏線・手がかり・設定など、話の中の大事な物を書きます。いっしょに崩れる要素を「関係する要素」に書いておくと、片方を選んだときに、もう片方の場面も出ます（どちらの向きに書いても出ます。たどるのは1段だけで、関係の先の先までは追いません）
  • 「場面」: 章と場面を、話の順に上から書きます。上から並べた順が、そのまま「直す場所」の並び順になります
  • 「つながり」: どの要素が、どの場面に、どう書かれているか（台詞・地の文・描写・手がかり・回想）と、強さ（必ず直す・見直す・念のため）を書きます。台詞はそのまま写しておくと、直すときに本文から探しやすくなります
  • 「直す場所」: 選んだ要素と、関係する要素が出てくる場面が、章の順に並びます。「必ず直す」の行は赤。直したら「済み」に ○ を付けると、取り消し線になり、「まだ直していない」の数が減ります
  • 書き間違い（要素に無い ID、場面 ID の書き忘れ、関係する要素に無い ID など）は、「変える」の「注意」の欄に出ます
  • 書ける数: 要素 80・場面 120・つながり 600 行まで

動く環境

確かめたこと・確かめていないこと

  • Windows 11 のパソコンの Excel で再計算し、記入例の10個の要素それぞれを選んだときの「直す場所」を、別の方法で計算した答えと照らし合わせて、10通りとも全部一致しました。わざと書き間違いを入れた表で「注意」が出ること、白紙でエラーが出ないこと、「必ず直す」の行に色が付くことも確かめています
  • Google スプレッドシート・LibreOffice でも使える関数だけで作っていますが、それらで実際に開いての確かめは、まだしていません。Mac の Excel・スマホのアプリも確かめていません
  • 表が見るのは、書き込んだ関係だけです。書いていない関係や、書き直したことで新しく生まれる食い違いは出ません。最後はご自身の目でお確かめください
