使っているところ

音は出ません。画面のデータは架空の例です。

こんな人に

  • 車に毎月いくらかかっているのか、ちゃんと知りたい
  • 燃費が落ちていないか、給油のたびに確かめたい
  • オイル交換や車検、保険の更新を「気づいたら過ぎていた」ことがある
  • 家族の車など、2台分をまとめて記録したい
  • 表計算は苦手。でも黄色いマスに書くだけなら使えそう

できること

  • 給油を書くと燃費が出る：日付・メーター・入れた量・金額を1行書くと、燃費（1Lで何km走れたか）と1kmあたりのガソリン代が自動で出ます（満タン法）
  • 満タンにしなかった給油もOK：「途中まで」を選ぶと、次に満タンにした行でまとめて燃費を計算します
  • 維持費を科目ごとに集計：ガソリン・税金・保険・車検・点検・整備・オイル交換・タイヤ・駐車場・高速・有料道路・洗車・その他。月ごと・年ごと（選んだ年とその前の4年）の合計を出します
  • 1kmあたりの維持費：その年に走った距離（給油の記録のメーターから出します）で割った目安を出します
  • 月極の駐車場代は1回書くだけ：月の金額とはじめた月を書くと、毎月の維持費に自動で入ります
  • 次の予定が近づくと色でお知らせ：オイル交換・車検・保険の更新などの「次の予定日」「次のメーター」を書いておくと、30日以内／500km以内で色がつきます（日数とkmは変えられます）
  • 車は2台まで：集計は1台ずつでも、2台あわせても見られます
  • 書きまちがいに気づける：メーターが前より小さい・日付が前の記録より古い・数字のマスに文字が入っている、などのときは「〇〇を確認」と出て、その行は計算に入りません

中身

Excel ファイル（.xlsx）1つ。シートは6枚です。

  1. 使い方 … 3ステップの説明と、燃費の出し方。やさしい言葉で書いています
  2. 車 … 呼び名・今のメーター・月極の駐車場代
  3. 給油 … 300行
  4. 整備・費用 … ガソリン以外のお金。100行
  5. 予定 … 次のオイル交換・車検など。30行
  6. 集計 … 月ごと・年ごとの維持費、1kmあたりの費用、平均の燃費
  • 例の行（架空のデータ）が入っています。消してからお使いください
  • 車検の時期や税金・保険の期限は、車や契約によってちがうため決めつけていません。車検証や届いた通知、保険証券などで確かめて書きこむ形です
  • 計算式が入ったところは、誤って消さないためのロックをかけてあります（パスワードなし。外すこともできます）
  • A4横で印刷できる設定です。印刷の前にプレビューで確かめてください
  • マクロ（VBA）は使っていません。計算式だけで作っています。

動く環境

  • パソコンの Microsoft Excel（Windows 版）で動作を確かめています。Google スプレッドシート、Mac の Excel・Numbers、スマホ・タブレットでの動作は保証していません。
